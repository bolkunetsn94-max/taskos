# TASK//OS: PWA-планер

## Что в архиве
- `index.html`: само приложение
- `sw.js`: service worker (офлайн-кэш и выдача .ics для Календаря)
- `manifest.webmanifest`: название, иконки, полноэкранный режим
- `icon-*.png`: иконки 180/192/512

## Публикация на GitHub Pages (бесплатно, ~5 минут)
1. github.com → **New repository** → имя `taskos` → Public → Create.
2. **Add file → Upload files** → перетащи **содержимое** папки (не саму папку: `index.html` должен лежать в корне) → Commit.
3. **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/taskos/`.

Альтернатива: app.netlify.com/drop. Перетащи папку, зарегистрируйся, чтобы ссылка не удалилась.

## Установка на iPhone
1. Открой ссылку **в Safari** (не в Chrome и не в Telegram).
2. **Поделиться → На экран «Домой»** → Добавить.
3. Запусти приложение с иконки **один раз при включённом интернете**, чтобы закэшировались шрифты. После этого оно работает полностью офлайн.
4. ⚙ → **Системные уведомления** → Разрешить (iOS 16.4+, только в установленном приложении).

## Напоминания: как они работают
| Ситуация | Что срабатывает |
|---|---|
| Приложение открыто | Окно на весь экран, звук, вибрация, системное уведомление |
| Приложение свёрнуто или закрыто | iOS не даёт веб-приложениям будить себя по таймеру без сервера. Поэтому нажми **иконку календаря** у задачи (или ⚙ → «Экспорт в Календарь»), затем «Добавить». Напоминание придёт от Календаря iPhone, офлайн |

## Обновление
Меняешь файлы в репозитории и **поднимаешь `VERSION` в `sw.js`** (например `taskos-v1.0.1`). Иначе iPhone продолжит показывать старую версию из кэша.

## Данные
Хранятся только на устройстве (localStorage). У Safari и у иконки на экране «Домой» **разные хранилища**. Перенос данных: ⚙ → «Резервная копия», затем «Восстановить».
